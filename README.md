# TestingAI — «Темный Бог Надувных Замков»

3D-прототип на **Godot Engine 4.7.2** (исходный код проекта, не APK).
Открывается в редакторе Godot 4.7.2, запускается на ПК и Android (отладка).

## Технический стек
- Движок: Godot 4.7.2, рендеринг **Mobile** (3D, стиль PS3).
- Физика: **Jolt Physics** (Physics Engine = Jolt).
- Аэродинамика: узлы `AeroBody3D` / `AeroInfluencer3D` (плагин Godot Aerodynamic Physics v0.9.1+; в репозитории — функциональная заглушка в `addons/godot_aerodynamic_physics`).
- Аудио: Ogg Vorbis (`.ogg`).
- Управление: сенсорное (виртуальный джойстик, свайп камеры, экранные кнопки).

## Структура
- `project.godot` — настройки проекта (Mobile рендерер, Jolt, слои физики, автозагрузка).
- `scenes/` — сцены: меню, игровой мир, замок НЗТБНЗ, игрок, чанки terrain, меню отладки.
- `scripts/` — геймплейные скрипты GDScript.
- `assets/audio/` — звуки и музыка (Ogg Vorbis).
- `assets/textures/` — текстуры биомов, замка, интерфейса.

## Запуск
1. Установите Godot 4.7.2.
2. Откройте папку проекта как проект Godot.
3. Включите плагин Aerodynamic Physics в Project Settings → Plugins (или используйте заглушку).
4. Запустите «Некоторая сцена» → `res://scenes/MainMenu.tscn`.

Размер папки проекта (без кэша импорта `.godot`) поддерживается в диапазоне 128–511 МБ.
