# Godot Aerodynamic Physics

Папка содержит ЗАГЛУШКУ плагина. Для финальной сборки установите настоящий
плагин **Godot Aerodynamic Physics (v0.9.1 или новее)** из библиотеки ассетов
Godot Engine (Asset Library) и замените им содержимое
`addons/godot_aerodynamic_physics/`.

Заглушка предоставляет узлы `AeroBody3D` и `AeroInfluencer3D` (через `class_name`),
因此 сцены используют эти типы напрямую и остаются совместимыми с настоящим плагином.
